## Rules

- **Synthetic only.** Newly written; nothing copied from production; no real names, e-mails, photos or files. Identities use the reserved `.test` top-level domain (RFC 2606), so they can never reach a real mailbox.
- **Deterministic:** fixed UUIDs (`…-a000-…` showcase, `…-b000-…` fixtures) and fixed usernames; re-running is a no-op.
- **Fixture accounts are created through the real sign-up trigger** (`on_auth_user_created`), so the account-to-user mapping matches production behaviour.
- **Load order:** baseline → `showcase.sql` → `fixtures.sql`.
- **Never add real user data**, and never run the fixture seed on production.
